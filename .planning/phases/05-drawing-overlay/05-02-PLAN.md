**Part A: Complete the line tool in `src/hooks/useDrawing.ts`**

The `onPointerDown`, `onPointerMove`, `onPointerUp` handlers already exist from plan 05-01. Extend them for the line tool:

**Line tool behavior:**
- `onPointerDown`: Same as freehand — create new `Stroke` with tool="line" and the starting point. The stroke starts with just one point.
- `onPointerMove`: For line tool, replace `points[1]` (the endpoint) rather than appending. This creates a live "rubber band" preview of the line as the user drags. Implementation: `currentStrokeRef.current.points = [currentStrokeRef.current.points[0], point]` (always keep the origin, replace the end). Then `redrawCanvas(canvas, strokes, currentStrokeRef.current)`.
- `onPointerUp`: Same commit logic — push completed stroke to `strokes`. A line stroke always has exactly 2 points: `[start, end]`.

**`redrawCanvas` for line tool (update the existing branch):**
```ts
// line tool: draw from first point to last point
if (stroke.tool === "line" && stroke.points.length >= 2) {
  const start = stroke.points[0];
  const end = stroke.points[stroke.points.length - 1];
  ctx.beginPath();
  ctx.moveTo(start.x, start.y);
  ctx.lineTo(end.x, end.y);
  ctx.stroke();
}
```

**Undo/redo — fix implementation to use refs to avoid stale closure:**

The plan 05-01 draft used `setStrokes` with a functional updater, but undo also needs to push to `undoneStrokes` atomically. Use this pattern:

```ts
const strokesRef = useRef<Stroke[]>([]);
const undoneStrokesRef = useRef<Stroke[]>([]);
```

Keep these in sync with the corresponding state in useEffect:
```ts

useEffect(() => { undoneStrokesRef.current = undoneStrokes; }, [undoneStrokes]);
```

**undo:**
```ts
const undo = useCallback(() => {
  const current = strokesRef.current;
  if (current.length === 0) return;
  const removed = current[current.length - 1];
  const next = current.slice(0, -1);
  setStrokes(next);
  setUndoneStrokes(prev => [...prev, removed]);
  if (canvasRef.current) redrawCanvas(canvasRef.current, next);
}, []);
```

**redo:**
```ts
const redo = useCallback(() => {
  const undone = undoneStrokesRef.current;
  if (undone.length === 0) return;
  const stroke = undone[undone.length - 1];
  const nextUndone = undone.slice(0, -1);
  setUndoneStrokes(nextUndone);
  const next = [...strokesRef.current, stroke];
  setStrokes(next);
  if (canvasRef.current) redrawCanvas(canvasRef.current, next);
}, []);
```

**clear:**
```ts
const clear = useCallback(() => {
  setStrokes([]);
  setUndoneStrokes([]);
  strokesRef.current = [];
  undoneStrokesRef.current = [];
  if (canvasRef.current) {
    const ctx = canvasRef.current.getContext("2d");
    ctx?.clearRect(0, 0, canvasRef.current.width, canvasRef.current.height);
  }
}, []);
```

**Part B: Add ResizeObserver to `src/components/DrawingOverlay.tsx`**

Replace the simple `useEffect` that sets `canvas.width/height` once with a `ResizeObserver` that keeps canvas pixel dimensions synced to its layout dimensions at all times (DRAW-12):

```tsx
useEffect(() => {
  const canvas = canvasRef.current;
  if (!canvas) return;

  const observer = new ResizeObserver(() => {
    // Save current drawing as image before resize (to restore after)
    const ctx = canvas.getContext("2d");
    // Save image data proportionally would require re-scaling strokes —
    // simpler: just resize the canvas. Drawings will clear on resize,
    // which is acceptable behavior for a session annotation tool.
    // The hook's strokes[] state is still intact; redraw after resize.
    canvas.width = canvas.offsetWidth;
    canvas.height = canvas.offsetHeight;
    // Signal the hook to redraw (DrawingOverlay doesn't have direct access to strokes).
    // Instead, pass an onResize callback prop that calls redrawCanvas.
    onResize?.();
  });

  observer.observe(canvas);
  return () => observer.disconnect();
}, [canvasRef, onResize]);
```
