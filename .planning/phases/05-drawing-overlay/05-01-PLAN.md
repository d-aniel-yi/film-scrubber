**Hook implementation `useDrawing()`:**

- `canvasRef = useRef<HTMLCanvasElement | null>(null)`
- State: `isDrawingMode` (boolean, default false), `activeTool` (DrawingTool, default "freehand"), `color` (string, default "#ff0000"), `strokeWidth` (number, default 3), `strokes` (Stroke[], default []), `undoneStrokes` (Stroke[], default [])
- `currentStrokeRef = useRef<Stroke | null>(null)` — tracks the in-progress stroke without re-renders
- `isPointerDownRef = useRef(false)` — tracks pointer down state

**Helper `getCanvasPoint(e, canvas)`:** Converts a pointer event to canvas-local coordinates using `canvas.getBoundingClientRect()`. Returns `{ x: e.clientX - rect.left, y: e.clientY - rect.top }`.

**Helper `redrawCanvas(canvas, strokes, currentStroke?)`:** Clears the canvas with `ctx.clearRect(0, 0, canvas.width, canvas.height)`, then iterates over `strokes` and optionally appends `currentStroke`. For each stroke:
- Set `ctx.strokeStyle = stroke.color`, `ctx.lineWidth = stroke.width`, `ctx.lineCap = "round"`, `ctx.lineJoin = "round"`
- For freehand: `ctx.beginPath()`, `ctx.moveTo(points[0].x, points[0].y)`, then `ctx.lineTo(p.x, p.y)` for each subsequent point, then `ctx.stroke()`
- For line tool (plan 05-02, but wire the branch now): same approach drawing from `points[0]` to `points[points.length - 1]`

**onToggleDrawing:** `setIsDrawingMode(v => !v)`. When toggling off, also call `redrawCanvas` to clear preview state.

**onPointerDown:** Only acts if `isDrawingMode`. Calls `e.currentTarget.setPointerCapture(e.pointerId)`. Gets canvas from `canvasRef.current`. Gets point via `getCanvasPoint`. Creates a new `Stroke` with current tool/color/width and the single starting point. Assigns to `currentStrokeRef.current`. Sets `isPointerDownRef.current = true`. Calls `redrawCanvas(canvas, strokes, currentStrokeRef.current)`.

**onPointerMove:** Only acts if `isDrawingMode && isPointerDownRef.current && currentStrokeRef.current`. Gets canvas and point. Pushes point to `currentStrokeRef.current.points`. Calls `redrawCanvas(canvas, strokes, currentStrokeRef.current)`.

**onPointerUp / onPointerLeave:** Only acts if `isPointerDownRef.current`. Sets `isPointerDownRef.current = false`. If `currentStrokeRef.current` has more than 1 point, calls `setStrokes(prev => [...prev, currentStrokeRef.current!])` and `setUndoneStrokes([])`. Resets `currentStrokeRef.current = null`. Calls `redrawCanvas(canvas, strokes)` (note: pass current strokes value from a ref or rely on the state update + useEffect for final redraw).

**IMPORTANT:** Because `setStrokes` is async, use a local variable for the committed strokes list in `onPointerUp` to avoid redrawing with stale state. Pattern:
```ts
const committed = [...strokes, stroke];
setStrokes(committed);
setUndoneStrokes([]);
currentStrokeRef.current = null;
isPointerDownRef.current = false;
redrawCanvas(canvas, committed);
```

**undo:** `setStrokes(prev => { const next = prev.slice(0, -1); redrawCanvas(canvasRef.current!, next); return next; })`. Also `setUndoneStrokes(prev => [...prev, strokes[strokes.length - 1]])`. Use a snapshot pattern to avoid stale closure — capture `strokes` at call time.

**redo:** `setUndoneStrokes(prev => { const stroke = prev[prev.length - 1]; if (!stroke) return prev; const next = prev.slice(0, -1); setStrokes(s => { const committed = [...s, stroke]; redrawCanvas(canvasRef.current!, committed); return committed; }); return next; })`.

**clear:** `setStrokes([]); setUndoneStrokes([]); if (canvasRef.current) { const ctx = canvasRef.current.getContext("2d"); ctx?.clearRect(0, 0, canvasRef.current.width, canvasRef.current.height); }`.

**useEffect for redraw on strokes change:** `useEffect(() => { if (canvasRef.current && !isPointerDownRef.current) { redrawCanvas(canvasRef.current, strokes); } }, [strokes])`. This handles undo/redo/clear redraws.

Return all fields of `DrawingState`.

**Step A — Create `src/components/DrawingOverlay.tsx`:**

```tsx
"use client";

import { useEffect } from "react";
import type { DrawingState } from "@/hooks/useDrawing";

type DrawingOverlayProps = Pick<DrawingState,
  "isDrawingMode" | "canvasRef" | "onPointerDown" | "onPointerMove" | "onPointerUp" | "onPointerLeave"
>;

export function DrawingOverlay({
  isDrawingMode,
  canvasRef,
  onPointerDown,
  onPointerMove,
  onPointerUp,
  onPointerLeave,
}: DrawingOverlayProps) {
  // Sync canvas pixel dimensions to its CSS layout dimensions on mount and resize.
  // This is a lightweight sync — ResizeObserver is added in plan 05-02.
  useEffect(() => {
    const canvas = canvasRef.current;
    if (!canvas) return;
    canvas.width = canvas.offsetWidth;
    canvas.height = canvas.offsetHeight;
  }, [canvasRef]);

  return (
    <canvas
      ref={canvasRef}
      className={[
        "absolute inset-0 h-full w-full",
        isDrawingMode
          ? "cursor-crosshair touch-none"   // touch-none: pointer events handle touch, not scroll
          : "pointer-events-none cursor-default",
      ].join(" ")}
      onPointerDown={isDrawingMode ? onPointerDown : undefined}
      onPointerMove={isDrawingMode ? onPointerMove : undefined}
      onPointerUp={isDrawingMode ? onPointerUp : undefined}
      onPointerLeave={isDrawingMode ? onPointerLeave : undefined}
      aria-label={isDrawingMode ? "Drawing canvas — draw on the video" : undefined}
      aria-hidden={!isDrawingMode}
    />
  );
}
```

Key design decisions:
- When `isDrawingMode` is false: `pointer-events-none` so clicks pass through to video (play/pause works)
- When `isDrawingMode` is true: canvas captures all pointer events (DRAW-03: video click-to-play disabled)
- `touch-none` when active: prevents scroll/zoom gestures from competing with drawing (DRAW-11)
- `absolute inset-0 h-full w-full`: canvas fills its relative parent exactly (DRAW-02, DRAW-12)
